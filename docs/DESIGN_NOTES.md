# 设计笔记

## 关键设计决策

### WinForms 而非 WPF

表格预览需要 DataGridView 原生支持，WinForms 的 DataGridView 在表格数据展示、行列操作、编辑模式方面比 WPF DataGrid 更直接。项目不需要复杂动画或样式系统。

### 内部数据模型：TableData

所有数据操作都通过 `TableData` 类，包含 Headers 和 Rows（List<List<string>>）。UI 层只做展示，数据变更统一走 Services 层，保证撤销栈一致性。

### 撤销栈

每次数据变更前 PushUndo 保存当前 TableData 快照，撤销时 Pop 恢复。撤销栈在导入新数据时清空。

### 模板与替换解耦

v2.6 起，模板库应用不再自动执行替换库规则。两个功能独立使用，避免级联修改后难以追溯。

### 筛选模板多匹配值

一个筛选模板包含多个匹配值时，按匹配值所在列拆分筛选分组，每组独立筛选后横向拼接。允许输出重名表头。

### 伪表格清洗策略

自动检测分隔符通过统计「整列均匀性」（一致性/覆盖率/最小列数）避免误伤单元格内符号。忽略纯空行和分隔线。
